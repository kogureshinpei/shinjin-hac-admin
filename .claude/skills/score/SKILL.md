# score スキル — サークル紹介サイト採点

## 概要

このスキルは新入生ハッカソンのサークル紹介サイト課題（HTML + Tailwind CSS）を70点満点で採点する。
GitHub リポジトリ URL または直接貼り付けられた HTML コードを受け取り、各採点項目を評価し、
採点サマリーと総評のみを出力する。

## 起動方法

**パターンA: GitHub URL を渡す**
```
/score https://github.com/student-name/circle-site
```

**パターンB: HTML を直接貼り付ける**
```
/score
<!DOCTYPE html>
...（index.html の内容をそのまま貼り付け）
```

---

## 動作手順

### Step 1: HTML を取得する

入力内容を判定して HTML を取得する。

**GitHub URL が渡された場合:**
- URL から raw コンテンツ URL を構築して WebFetch で取得する
- 変換ルール: `https://github.com/{user}/{repo}` → `https://raw.githubusercontent.com/{user}/{repo}/main/index.html`
- branch が `master` の場合は `main` を `master` に置き換える
- 404 等で取得できない場合は「指定されたリポジトリに index.html が見当たりませんでした。URL を確認してください。」と伝えてスキルを終了する

**HTML が直接貼り付けられた場合:**
- 入力内容をそのまま採点対象の HTML として使用する（WebFetch 不要）
- `<!DOCTYPE html>` や `<html` で始まっている場合は HTML の直接入力と判断する

### Step 2: HTML を採点する

取得した HTML ソースコードを、下記の採点基準に従って各項目ごとに評価する。

**評価の原則:**
- Tailwind クラスの有無は HTML の文字列として判定する（ブラウザでの実際のレンダリングは不要）
- `class="..."` 属性の中から対象クラスを探す。`px-4`, `py-2`, `p-6` のような具体的なクラス名が含まれているかを確認する
- `flex-1`, `w-full` のようなクラスも同様に文字列検索で確認する
- プレースホルダー（`【】` で囲まれた文字列）が残っている場合は「内容未記入」扱いとするが、HTML の構造・クラスの実装は評価対象とする
- `href="#"` のみのリンクはプレースホルダーとみなす

### Step 3: 採点結果を出力する

下記「出力フォーマット」のテンプレートをそのまま使い、`＿＿` を実際の点数で埋めて出力する。

## 採点基準（70点満点）

### 0. タイトル設定 ／ 3点

**① `<title>` タグの変更（3点）**
- 3点: `<title>` に独自のサークル名・チーム名など固有の文字列が設定されており、デフォルト値（「Document」「ドキュメント」等）でも、テンプレートのプレースホルダー（「【サークル名】」等）でもない
- 1点: デフォルト「Document」からは変更されているが、テンプレートのプレースホルダー「【サークル名】」のまま（内容未入力だが作業の痕跡がある）、または「index」「test」等の汎用的な文字列
- 0点: デフォルト値「Document」のまま、または `<title>` が存在しない

### 1. ヘッダー ／ 18点

**▼ 間隔（6点）**

**① ヘッダー内の余白（3点）**
- 3点: `px-*` と `py-*`（または `p-*`）が適用されており、ロゴ・ナビが端に張り付かず余裕がある
- 1点: どちらか一方のみ、または余白が極端に小さい
- 0点: 余白クラスがない

**② ロゴとナビの間隔（3点）**
- 3点: `justify-between` によりロゴとナビが左右に広がり、適切な間隔が生まれている
- 1点: `justify-between` はないが `gap-*` や `mr-*` 等で間隔は取れている
- 0点: 間隔がなく隣接している

**▼ 内容（12点）**

**③ ヘッダーの固定表示（3点）**
- 3点: `fixed`（または `sticky`）・`top-0`・`w-full`・`z-*` が揃っており、スクロールしても上部に留まる
- 2点: 固定クラスはあるが `z-*` や `w-full` が不足してスクロール時に崩れる恐れがある
- 0点: 固定されていない

**④ ロゴとナビの横並び配置（3点）**
- 3点: 親要素に `flex` と `justify-between` が付き、ロゴが左・ナビが右に配置されている
- 1点: `flex` はあるが `justify-between` がない、または左右どちらかに寄っている
- 0点: 横並びになっていない

**⑤ 垂直方向の中央揃え（3点）**
- 3点: `items-center` が付いており、ロゴとナビの高さが揃っている
- 1点: クラスはないが見た目上ほぼ揃っている
- 0点: 明らかにズレている

**⑥ ナビゲーションリンク（3点）**
- 3点: アンカーリンク（`href="#..."` 形式、`#` 以降に具体的な id がある）が2つ以上ある
- 1点: リンクはあるが `href="#"` のプレースホルダーのまま
- 0点: ナビゲーションがない

### 2. 背景画像（Hero） ／ 6点

**▼ 間隔（2点）**

**① テキストの余白・位置（2点）**
- 2点: テキストが中央寄せ（`text-center`・`items-center`・`justify-center` 等）で、適切な位置に置かれている
- 1点: 一部の中央寄せクラスのみ、または位置が若干ズレている
- 0点: テキストが端に寄っている、または位置指定がない

**▼ 内容（4点）**

**② 全面背景画像の実装（2点）**
- 2点: `h-screen`（または同等）+ `bg-cover` + `bg-center` が揃い、画像が画面いっぱいに広がっている
- 1点: 背景画像はあるが高さが不足、または `bg-cover` がなく画像が切れる
- 0点: 背景画像がない（`bg-[url(...)]` や `style="background-image:..."` も含めて判断）

**③ テキストの視認性（2点）**
- 2点: オーバーレイ（`bg-black/XX` 等）と `text-white` 等の両方により、背景の上でテキストが読める
- 1点: どちらか一方のみ
- 0点: テキストが背景に溶け込んで読みにくい

### 3. 活動紹介 ／ 8点

**▼ 間隔（2点）**

**① セクションの上下余白（1点）**
- 1点: `py-*`（または `pt-*`・`pb-*`）で前後セクションとの間隔が確保されている
- 0点: 上下余白がなく隣のセクションと密着している

**② 見出し〜コンテンツ間の余白（1点）**
- 1点: 見出しまたはその wrapper に `mb-*` が付いており、見出しとカード群の間に間隔がある
- 0点: 見出しとコンテンツが詰まっている

**▼ 内容（6点）**

**③ セクションの区切りと見出し（2点）**
- 2点: `<section>` 等で区切られ、`<h2>` 等の見出しがある
- 1点: 区切りまたは見出しのどちらかが欠けている
- 0点: 両方欠けている

**④ 活動内容のブロック構成（4点）**
- 4点: 活動内容が複数のブロック要素（カード等）に分かれて整理され、`gap-*` や `p-*` で内部余白もある
- 2点: ブロックはあるが1つのみ、または内部余白がない
- 0点: ブロック要素で構成されていない

### 4. 自己紹介 ／ 8点

**▼ 間隔（2点）**

**① セクションの上下余白（1点）**
- 1点: `py-*` で前後セクションとの間隔が確保されている
- 0点: 上下余白がない

**② カード内部の余白（1点）**
- 1点: 写真・テキストを囲む要素に `p-*` が付いており、内容が端に張り付いていない
- 0点: 内部余白がない

**▼ 内容（6点）**

**③ 写真とテキストのレイアウト（2点）**
- 2点: `flex` でPC幅では写真とテキストが横並びになっている
- 1点: 縦並びだが構造は整っている
- 0点: 写真またはテキストが欠けている

**④ 丸みと影（2点）**
- 2点: 写真またはカードに `rounded-*` と `shadow-*` の両方がある
- 1点: どちらか一方のみ
- 0点: なし

**⑤ 見出しとコンテンツの距離（2点）**
- 2点: 見出しに `mb-*` 等があり、カードとの間に適切な間隔がある
- 1点: 間隔はあるが小さい
- 0点: 見出しとカードが詰まっている

### 5. メンバー紹介 ／ 8点

**▼ 間隔（2点）**

**① セクションの上下余白（1点）**
- 1点: `py-*` で前後セクションとの間隔が確保されている
- 0点: 上下余白がない

**② カード間・カード内の余白（1点）**
- 1点: `gap-*` でカード間に間隔があり、かつ各カード内に `p-*` がある
- 0点: カードが詰まっている、または内部余白がない

**▼ 内容（6点）**

**③ grid による2×3レイアウト（2点）**
- 2点: 親要素に `grid grid-cols-3 grid-rows-2` が付き、カードが2行3列のグリッドで配置されている
- 1点: `grid` と `grid-cols-3` は使われているが `grid-rows-2` がない、または1行のみの配置
- 0点: `flex` を使った横並び、または横並びになっていない

**④ カードの非対称配置（2点）**
- 2点: `col-start-*` と `row-start-*` で3枚が (row1,col2)・(row2,col1)・(row2,col3) の位置に配置されている
- 1点: `col-start-*` または `row-start-*` のどちらか一方のみ
- 0点: 配置指定がない、または全カードが同じ行に並んでいる

**⑤ カードの丸みと影（2点）**
- 2点: 各カードに `rounded-*` と `shadow-*` の両方がある
- 1点: どちらか一方のみ
- 0点: なし

### 6. フッター ／ 8点

**▼ 間隔（2点）**

**① フッター内の上下余白（1点）**
- 1点: `py-*` がフッターに付いており、コンテンツが上下に詰まっていない
- 0点: 上下余白がない

**② フッター内要素間の余白（1点）**
- 1点: サークル名・SNSリンク・コピーライト間に `mb-*` または `gap-*` があり、適切な間隔が取れている
- 0点: 要素が詰まっている

**▼ 内容（6点）**

**③ サークル名の表示（2点）**
- 2点: フッターにサークル名またはロゴが適切にスタイリングされて表示されている
- 1点: 表示はあるがプレースホルダーのまま、またはスタイリングが不十分
- 0点: ない

**④ 連絡先・SNSリンク（2点）**
- 2点: SNSまたはメールアドレスのリンクが2つ以上ある
- 1点: 1つのみ
- 0点: ない

**⑤ コピーライトと背景スタイル（2点）**
- 2点: コピーライト表記（`©` や `Copyright` 等）があり、`bg-*` でフッターに背景色が付いている
- 1点: どちらか一方のみ
- 0点: どちらもない

### 7. 擬似クラス・擬似要素 ／ 11点

**① `hover:` 擬似クラスが複数箇所に設定されている（4点）**
- 4点: ナビリンク・カード・画像・フッターリンクなど、3箇所以上に `hover:` エフェクトがある
- 2点: 1〜2箇所のみに `hover:` がある
- 0点: `hover:` が使われていない

**② `transition` で変化が滑らか（4点）**
- 4点: `transition` または `transition-*` が設定されており、ホバー時の変化がアニメーションする
- 2点: `transition` はあるが一部の要素のみ
- 0点: `transition` が使われておらず変化が瞬時に切り替わる

**③ `::before` / `::after` 擬似要素（または `before:` / `after:` ユーティリティ）が使われている（3点）**
- 3点: `content: ''`（Tailwind では `content-['']`）を伴う擬似要素が1箇所以上あり、装飾またはアニメーションに使われている
- 1点: 記述はあるが `content` が欠けているなど不完全
- 0点: 使われていない

## 出力フォーマット

**採点サマリー・減点まとめ・優れた点・総評を出力する。項目ごとの詳細（得点・コメント）は出力しない。**

提出者名は GitHub URL の場合はリポジトリ名、HTML 直接入力の場合は「（直接入力）」とする。
総評は全体を踏まえた講評を3〜5文で日本語で記述する。

減点まとめは、減点があった項目のみ箇条書きで列挙する。減点がない場合は「減点なし」と記載する。
最優先改善アドバイスは、減点項目の中で最も影響が大きく取り組みやすいものを50文字程度で1文にまとめる。

優れた点は、満点または特に完成度が高かった項目を2〜3点ピックアップし、何がよかったかを具体的なクラス名を交えて1〜2文で説明する。
